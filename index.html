Privacy & Responsible AI

Privacy

  • Demo uses synthetic data.
  • No bank credentials are required.
  • No passwords, PINs, OTPs or CVVs are requested.
  • Production systems should use encryption.
  • Production systems should use access controls.
  • Users should be able to correct inaccurate information.

Responsible AI

Fairness

Protected characteristics should not be used for scoring.

Explainability

Users should understand the main factors behind results.

Human Oversight

FinGuard AI does not replace lenders or banks.

Uncertainty

AI outputs are estimates and indicators.

User Control

Users should be able to review and correct information.

Prototype Limitations

  • Uses synthetic/demo data.
  • Credit readiness is only an estimate.
  • Transaction anomalies do not prove fraud.
  • Alternative data may be incomplete.
  • Real deployment requires secure financial-data integration.
  • Real deployment requires applicable regulatory compliance.
  • Human/lender review remains necessary.
